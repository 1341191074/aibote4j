# 🚀 启动顺序说明

## 📋 概述

Aibote4J 采用服务端-客户端架构，正确的启动顺序对于系统的正常运行至关重要。本文档将详细说明整个启动流程。

## 🔧 启动顺序详解

### 第一步：启动服务端

服务端是整个系统的核心，负责监听客户端连接并管理自动化任务。

```java
import net.aibote.Application;

public class ServerStarter {
    public static void main(String[] args) {
        // 启动服务端应用
        Application.main(args);
    }
}
```

**服务端启动过程：**
1. 注册默认任务（如记事本自动化任务）
2. 启动三个平台的服务端：
   - **Windows服务端** - 端口 16999
   - **Web服务端** - 端口 16998  
   - **Android服务端** - 端口 16997
3. 服务端开始监听对应端口，等待客户端连接

### 第二步：启动客户端

客户端连接到服务端后，服务端会自动为其创建对应的机器人实例并执行已注册的任务。

#### Windows客户端启动示例：

```java
import net.aibote.examples.ClientDriverStartupExample;

public class ClientStarter {
    public static void main(String[] args) {
        // 启动Windows客户端驱动
        String driverPath = "E:\\Aibote\\";
        String serverIp = "127.0.0.1";
        String serverPort = "16999"; // 对应Windows服务端端口
        
        ClientDriverStartupExample.startWinClientDriver(driverPath, serverIp, serverPort);
    }
}
```

#### Web客户端启动示例：

```java
import net.aibote.examples.ClientDriverStartupExample;

public class WebClientStarter {
    public static void main(String[] args) {
        // 启动Web客户端驱动
        ClientDriverStartupExample.startWebClientDriver(
            "127.0.0.1",    // serverIp
            "16998",        // serverPort (Web服务端端口)
            "chrome",       // browserName
            null,           // browserPath
            "0",            // debugPort
            null,           // argument
            null,           // userDataDir
            null            // webDriverPath
        );
    }
}
```

### 第三步：自动任务执行

当客户端成功连接到服务端后：

1. 服务端检测到新客户端连接
2. 自动为客户端创建对应的机器人实例（WinBot/WebBot/AndroidBot）
3. 等待5秒后自动执行已注册的默认任务
4. 任务执行完成后，机器人实例保持连接状态等待进一步指令

## ⚠️ 常见错误和注意事项

### 错误的启动顺序

❌ **错误做法：先启动客户端**
```java
// 这样做是错误的！
public class WrongOrder {
    public static void main(String[] args) {
        // 先启动客户端（此时服务端还没启动）
        ClientDriverStartupExample.startWinClientDriver("path", "ip", "port");
        
        // 再启动服务端（太晚了！）
        Application.main(args);
    }
}
```

✅ **正确做法：先启动服务端**
```java
// 这样做是正确的！
public class CorrectOrder {
    public static void main(String[] args) {
        // 先启动服务端
        Application.main(args);
        
        // 客户端会在另一个进程中启动
        // 或者在服务端启动后再单独启动客户端
    }
}
```

### 端口对应关系

确保客户端连接到正确的服务端端口：

| 平台类型 | 服务端端口 | 客户端类型 |
|---------|-----------|-----------|
| Windows | 16999 | WindowsDriver.exe |
| Web | 16998 | WebDriver.exe |
| Android | 16997 | AndroidDriver.exe |

### 连接验证

可以通过以下方式验证连接是否成功：

```java
// 在服务端日志中查看连接信息
/*
[INFO] 新的链接： xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx
[INFO] 创建WIN机器人实例成功
[INFO] 执行默认任务, 停止5秒
*/

// 在客户端可以看到类似输出
/*
WindowsDriver.exe 127.0.0.1 16999
启动driver
*/
```

## 🛠️ 实际部署建议

### 开发环境

```bash
# 1. 启动服务端（终端1）
mvn exec:java -Dexec.mainClass="net.aibote.Application"

# 2. 启动客户端（终端2）
mvn exec:java -Dexec.mainClass="net.aibote.examples.ClientDriverStartupExample"
```

### 生产环境

```bash
# 使用脚本启动服务端
#!/bin/bash
nohup java -jar aibote-server.jar > server.log 2>&1 &

# 使用脚本启动客户端
#!/bin/bash
nohup ./WindowsDriver.exe 127.0.0.1 16999 > client.log 2>&1 &
```
