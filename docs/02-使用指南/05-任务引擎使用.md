# 🚀 任务引擎使用指南

## 📋 概述

任务引擎是 Aibote4J 框架的核心组件之一，它提供了一套完整的任务管理系统，让您可以轻松地定义、注册和执行自动化任务。相比直接调用机器人API，任务引擎提供了更好的组织性、可维护性和自动化能力。

## 🎯 核心概念

### 什么是任务引擎？

任务引擎是一个集中式的任务管理器，负责：
- **任务注册** - 将自动化任务注册到系统中
- **任务调度** - 根据条件自动执行任务
- **任务执行** - 管理任务的完整执行生命周期
- **任务监控** - 跟踪任务执行状态和结果

### 为什么使用任务引擎？

1. **简化复杂流程** - 自动处理连接、执行、清理等步骤
2. **提高可维护性** - 任务逻辑集中管理，易于修改和扩展
3. **增强自动化** - 客户端连接时自动执行预设任务
4. **更好的组织性** - 将相关操作封装成独立的任务单元

## 🛠️ 快速入门

### 1. 创建任务类

```java
import net.aibote.task.impl.NotepadAutomationTask;

// 创建记事本自动化任务
NotepadAutomationTask task = NotepadAutomationTask.builder()
    .taskName("记事本自动化任务")
    .scriptName("Notepad-Bot")
    .description("自动查找记事本窗口并执行基本操作")
    .build();
```

### 2. 注册任务

```java
import net.aibote.task.TaskEngine;

// 获取任务引擎实例并注册任务
String taskId = TaskEngine.getInstance().registerTask("notepad-task", task);
System.out.println("任务已注册，ID: " + taskId);
```

### 3. 启动服务端

> ⚠️ **重要**：必须严格按照以下顺序启动

**第一步：启动服务端**
```java
import net.aibote.Application;

// 启动服务端应用，开始监听客户端连接
Application.main(new String[]{});
```

**第二步：启动客户端**
服务端启动成功后（显示端口监听信息），再启动对应的客户端驱动：

```java
// Windows客户端示例
import net.aibote.examples.ClientDriverStartupExample;

ClientDriverStartupExample.startWinClientDriver(
    "E:\\Aibote\\",     // driverPath
    "127.0.0.1",         // serverIp  
    "16999"              // serverPort (对应Windows服务端)
);
```

**完整启动流程**：
1. 服务端启动 → 监听端口16997-16999
2. 客户端连接 → 服务端创建机器人实例
3. 自动执行 → 注册的任务在5秒后自动执行

## 📚 详细使用

### 任务定义

每个任务都需要实现 `TaskDefinition` 接口：

```java
@Data
@Builder
public class CustomTask implements TaskDefinition {
    
    private String taskName;
    private String scriptName;
    private String description;
    
    @Override
    public Set<BotFactory.BotType> getSupportedBotTypes() {
        // 指定支持的机器人类型
        return Set.of(BotFactory.BotType.WIN);
    }
    
    @Override
    public TaskExecutor getTaskExecutor() {
        // 返回任务执行器
        return this::executeTask;
    }
    
    /**
     * 任务执行逻辑
     */
    private void executeTask(AbstractPlatformBot bot) throws Exception {
        // 在这里编写具体的自动化逻辑
        if (!(bot instanceof WinBot)) {
            throw new IllegalArgumentException("此任务仅支持Windows机器人");
        }
        
        WinBot winBot = (WinBot) bot;
        
        // 示例：查找记事本窗口并移动鼠标
        String notepadWindow = winBot.findWindow("Notepad", "");
        if (notepadWindow != null) {
            winBot.moveMouse(notepadWindow, 100, 100, Mode.front, "");
        }
    }
}
```

### 任务注册和管理

```java
TaskEngine engine = TaskEngine.getInstance();

// 注册多个任务
NotepadAutomationTask task1 = NotepadAutomationTask.builder()
    .taskName("任务1")
    .scriptName("Script-1")
    .build();

NotepadAutomationTask task2 = NotepadAutomationTask.builder()
    .taskName("任务2")
    .scriptName("Script-2")
    .build();

String id1 = engine.registerTask("task-1", task1);
String id2 = engine.registerTask("task-2", task2);

// 查询任务
TaskDefinition task = engine.getTask(id1);
System.out.println("任务名称: " + task.getTaskName());

// 获取所有任务
Map<String, TaskDefinition> allTasks = engine.getAllTasks();
System.out.println("总任务数: " + allTasks.size());

// 移除任务
engine.removeTask(id1);
```

### 手动执行任务

```java
// 手动执行指定任务
TaskEngine engine = TaskEngine.getInstance();
engine.executeTask("task-id", channelContext, BotFactory.BotType.WIN);
```

## 🎯 NotepadAutomationTask 详解

### 任务功能

`NotepadAutomationTask` 是一个内置的示例任务，演示了基本的Windows自动化操作：

```java
public class NotepadAutomationTask implements TaskDefinition {
    
    // 任务基本信息
    private String taskName;
    private String scriptName;  
    private String description;
    
    @Override
    public Set<BotFactory.BotType> getSupportedBotTypes() {
        // 仅支持Windows平台
        return Set.of(BotFactory.BotType.WIN);
    }
    
    private void executeTask(AbstractPlatformBot bot) throws Exception {
        // 确保是WinBot类型
        if (!(bot instanceof WinBot)) {
            throw new IllegalArgumentException("此任务仅支持Windows机器人");
        }
        
        WinBot winBot = (WinBot) bot;
        
        // 等待3秒让系统稳定
        Thread.sleep(3000);
        
        // 查找资源管理器窗口
        String cabinetWindow = winBot.findWindow("CabinetWClass", "");
        System.out.println("找到窗口: " + cabinetWindow);
        
        // 在屏幕上移动鼠标
        winBot.moveMouse("", 100, 100, Mode.front, "");
    }
}
```

### 使用示例

```java
public class TaskExample {
    public static void main(String[] args) {
        // 1. 创建任务实例
        NotepadAutomationTask task = NotepadAutomationTask.builder()
            .taskName("我的记事本任务")
            .scriptName("My-Notepad-Bot")
            .description("自动化的记事本操作演示")
            .build();
        
        // 2. 注册任务
        String taskId = TaskEngine.getInstance().registerTask("my-notepad-task", task);
        System.out.println("任务注册成功，ID: " + taskId);
        
        // 3. 启动服务端（第一步）
        System.out.println("正在启动服务端...");
        Application.main(args);
        
        // 注意：客户端需要在另一个进程/终端中启动
        // 当Windows客户端连接时，会自动执行这个任务
    }
}

// 客户端启动代码（在另一个文件或进程中）
class ClientStarter {
    public static void main(String[] args) {
        // 等待服务端完全启动后执行
        try {
            Thread.sleep(3000); // 等待3秒确保服务端启动完成
        } catch (InterruptedException e) {
            Thread.currentThread().interrupt();
        }
        
        // 启动客户端（第二步）
        ClientDriverStartupExample.startWinClientDriver(
            "E:\\Aibote\\",
            "127.0.0.1", 
            "16999"
        );
    }
}
```

## ⚙️ 高级功能

### 任务配置

可以通过配置文件或环境变量来管理任务：

```yaml
# bot-config.yml
tasks:
  default:
    - notepad-task
    - web-scraping-task
  schedules:
    notepad-task:
      cron: "0 0 9 * * *"  # 每天9点执行
      enabled: true
```

### 任务监控

```java
// 监控任务执行状态
TaskEngine engine = TaskEngine.getInstance();

// 添加执行监听器
engine.addExecutionListener(new TaskExecutionListener() {
    @Override
    public void onTaskStarted(String taskId, TaskDefinition task) {
        System.out.println("任务开始: " + task.getTaskName());
    }
    
    @Override
    public void onTaskCompleted(String taskId, TaskDefinition task) {
        System.out.println("任务完成: " + task.getTaskName());
    }
    
    @Override
    public void onTaskFailed(String taskId, TaskDefinition task, Exception error) {
        System.out.println("任务失败: " + task.getTaskName() + ", 错误: " + error.getMessage());
    }
});
```

### 批量任务处理

```java
// 批量注册和执行任务
List<TaskDefinition> tasks = Arrays.asList(
    createNotepadTask(),
    createWebTask(),
    createAndroidTask()
);

List<String> taskIds = new ArrayList<>();
for (int i = 0; i < tasks.size(); i++) {
    String taskId = TaskEngine.getInstance().registerTask("batch-task-" + i, tasks.get(i));
    taskIds.add(taskId);
}

// 并发执行所有任务
taskIds.parallelStream().forEach(taskId -> {
    try {
        TaskEngine.getInstance().executeTask(taskId, channelContext, BotType.WIN);
    } catch (Exception e) {
        System.err.println("任务执行失败: " + taskId);
    }
});
```

## 📖 最佳实践

### 1. 任务设计原则

```java
// ✅ 好的做法
@Builder
public class WellDesignedTask implements TaskDefinition {
    private final String taskName;
    private final String scriptName;
    private final int retryCount;
    private final long timeoutMs;
    
    @Override
    public void executeTask(AbstractPlatformBot bot) throws Exception {
        // 添加重试机制
        for (int i = 0; i < retryCount; i++) {
            try {
                doExecute(bot);
                return; // 成功则退出
            } catch (Exception e) {
                if (i == retryCount - 1) throw e; // 最后一次尝试失败则抛出异常
                Thread.sleep(1000); // 等待后重试
            }
        }
    }
    
    private void doExecute(AbstractPlatformBot bot) throws Exception {
        // 具体的执行逻辑
    }
}
```

### 2. 错误处理

```java
@Override
public void executeTask(AbstractPlatformBot bot) throws Exception {
    try {
        // 主要逻辑
        performMainOperations(bot);
    } catch (CommandException e) {
        // 命令执行错误
        log.error("命令执行失败: {}", e.getMessage());
        handleCommandError(e);
    } catch (TimeoutException e) {
        // 超时错误
        log.error("操作超时: {}", e.getMessage());
        handleTimeoutError(e);
    } catch (Exception e) {
        // 其他错误
        log.error("未知错误", e);
        throw e; // 重新抛出以便任务引擎处理
    } finally {
        // 清理资源
        cleanupResources();
    }
}
```

## 🔧 故障排除

### 常见问题

1. **任务不执行**
   - 检查任务是否正确注册
   - 确认支持的机器人类型匹配
   - 验证客户端连接状态

2. **执行异常**
   - 查看详细错误日志
   - 检查机器人连接状态
   - 验证参数有效性

3. **性能问题**
   - 优化任务执行逻辑
   - 调整超时和重试配置
   - 考虑批量处理
